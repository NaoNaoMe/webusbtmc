Switch a modular instrument to USBTMC mode

Keysight (or Agilent) U27xx modular instruments stay in “firmware update” mode when they are powered on. This tool switches them to USBTMC mode, so that the other samples can use them. Do this each time the instrument is powered on.

  1. Connect the instrument with a USB cable.
  2. Press Switch to USBTMC mode and choose the instrument in the dialog of the browser. Only Keysight (Agilent) instruments are listed.
  3. The instrument restarts and appears as a new USB device. Wait a few seconds, then use it from the other samples.

On Windows the instrument may need the WinUSB driver in both modes: after the restart it is a different USB device (see the setup guide below).
