Command

Write sends the command. Read fetches the answer. Only a query (the command name is followed by ?) produces an answer. Press ↑ in the command field to recall earlier commands.

Transfer options
Binary: the selected file is sent after the command as a block (#…).
Use the binary block for answers that start with #, such as screen images.
